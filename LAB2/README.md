## **5. Задание 3. Предскажите результат:**

1. `2 + 3 * 4` 
   - Прогноз: 14 | Python: 14
   - Сначала идет умножение (3 * 4 = 12), потом сложение (2 + 12).

2. `(2 + 3) * 4` 
   - Прогноз: 20 | Python: 20
   - Из-за скобок сначала считается сложение (2 + 3 = 5), потом умножение (5 * 4).

3. `17 // 5` 
   - Прогноз: 3 | Python: 3
   - Это деление нацело (17 разделить на 5 получится 3 целых).

4. `17 % 5` 
   - Прогноз: 2 | Python: 2
   - Это остаток от деления (17 - 15 = 2).

5. `-7 // 2` 
   - Прогноз: -4 | Python: -4
   - Python округляет деление нацело всегда в меньшую сторону. Так как -3.5 меньше чем -3, получается -4.
