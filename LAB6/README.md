## Лабораторная работа №6. Списки и обработка наборов данных

### Файлы
statistics.py — статистика списка (количество, сумма, min, max, среднее)
transform.py — замена отрицательных чисел на модули в новом списке
positions.py — поиск всех индексов максимального элемента
variant.py — индивидуальный вариант №1 (Чётные числа)

**1. statistics.py:
Ввод: -2 0 5 3
Количество: 4
Сумма: 6
Минимум: -2
Максимум: 5
Среднее: 1.50

Ввод: (пустая строка)
Нет данных

**2. transform.py:
Ввод: -2 0 5 -2
Исходный список: [-2, 0, 5, -2]
Новый список: [2, 0, 5, 2]
(Исходный список сохранён без изменений)

**3. positions.py:
Ввод: 3 7 2 7 -> Вывод: [1, 3]
Ввод: 7 7 -> Вывод: [0, 1]

**4. variant.py:
Ввод: -8 -3 0 6 6 1
(Вариант 1 - Чётные числа)
Выборка: [-8, 0, 6, 6]
Количество: 4
Сумма: 4
Сортированная копия: [-8, 0, 6, 6]
