## Лабораторная работа №5. Строки и обработка текста

### Файлы
normalize.py — нормализация пробелов в тексте
palindrome.py — проверка на палиндром (игнорируя регистр и пробелы)
replace.py — замена символов с подсчётом
variant.py — индивидуальный вариант №1 (Слова, начинающиеся с 'а')

**1. normalize.py:
Ввод: " Один   два"
Исходная длина: 10
Новая длина: 8
Нормализованный текст: Один два
Количество слов: 2

**2. palindrome.py:
Ввод: А роза упала на лапу Азора -> Палиндром
Ввод: Python -> Не палиндром
Ввод: (пробелы) -> Нет текста

**3. replace.py:
Ввод: a::b:
Количество замен: 3
Новая строка: a--b-

**4. variant.py:
Ввод: Анна, армия! Я читаю. Книга, край, рама.
(Вариант 1 - Начинается с 'а')
анна
армия
Количество: 2
