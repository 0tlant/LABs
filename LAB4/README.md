## Лабораторная работа №4. Циклы, счётчики и накопители

### Файлы
- `range_numbers.py` — вывод чисел в диапазоне в обе стороны
- `statistics.py` — статистика потока чисел (сумма, количество положительных, максимум)
- `positive_input.py` — повторный ввод до получения положительного числа
- `variant.py` — индивидуальный вариант №1 (Чётные числа)

**1. range_numbers.py:
Ввод: 2 4   -> Вывод: 2, 3, 4
Ввод: 4 2   -> Вывод: 4, 3, 2
Ввод: 3 3   -> Вывод: 3

**2. statistics.py:
n=3, числа: -5 -2 -8
Сумма: -15
Количество положительных: 0
Максимум: -2

n=1, число: 0
Сумма: 0, положительных: 0, максимум: 0
**3. positive_input.py:
Ввод: 0, затем -2, затем 3
Квадрат числа: 9
Количество отклонённых попыток: 2
**4. variant.py:
n=7, числа: -12 -3 0 2 10 15 20
(Вариант 1 - Чётные числа)
Количество: 5
Сумма: 20
